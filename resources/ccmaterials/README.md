This is the path where the ccmaterials for the environment are supposed to be located. Load as many as you think necessary.

Download them with `blenderproc run code/load_cctextures.py --custom-blender-path <path-to-blender>` (edit `ASSETS_TO_DOWNLOAD` in that script), or place [ambientCG](https://ambientcg.com/) asset folders here manually, one folder per asset (e.g. `Bricks024/Bricks024_2K-JPG_Color.jpg`).
